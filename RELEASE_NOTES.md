# VGRPresenter 0.0.5

## What's new

- More reliable NDI live output, with sending moved off the UI thread.
- Improved live output and display behavior.
- Clearer computer health and performance information, with more color choices.

## Improvements

- Settings, menus, and pop-up windows are easier to use.
- Startup is smoother, with updates shown while the app loads.
- Saved style backgrounds are restored when opening a show on another computer.

## Fixes

- Fixed NDI async send and lifecycle issues that could hang or crash during live output.
- Opening Audio & Video settings no longer turns on audio monitoring.
- Adding an audio source is smoother.
- Pop-up windows no longer let clicks reach the screen behind them.
- Fixed issues with saved settings, displays, and slides.

## Windows downloads

- **VGRPresenter-Setup-0.0.5.exe** — recommended installer.
- **VGRPresenter-win64.zip** — portable version; unzip it and open the app.

Requires Windows 10 or newer.
